CENTRALE TOEGANGSCONTROLE

Rechtenmatrix

Elke rij is een gebruiker. De kolommen volgen Koepel → Schoolbestuur → School → Campus/vestiging → Module → Rechtenprofiel. Elk vinkje kent een recht uitsluitend toe op het aangeduide organisatieniveau. Er is geen automatische overerving naar onderliggende niveaus. Zoek op naam, e-mailadres of e-maildomein.
