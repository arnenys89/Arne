# Schoolwerkplan — Richtpunt campus Ninove–Zottegem

Interactieve, doorzoekbare weergave van het aangeleverde schoolwerkplan (155 pagina's).

- Alle 155 oorspronkelijke pagina's zijn opgenomen in content.json met bronpaginanummers.
- 13 hoofdstukken volgens de documentstructuur.
- Beleidsplan 2025–2029: 5 strategische doelen en operationele doelstellingen.
- Volledige tekstzoekfunctie, favorieten, leesvoortgang en persoonlijke doelstatussen.
- Statische applicatie op Cloudflare Pages; beveiliging via Cloudflare Access.

## Brongetrouwheid
De inhoud is tekstueel geëxtraheerd uit Schoolwerkplan.pdf. Pagina's met hoofdzakelijk schema's, afbeeldingen of tabellen kunnen beperkte tekstextractie hebben. Opvolgingsstatussen zijn persoonlijke notities in de browser en geen vastgestelde realisatiegegevens.

Deployment trigger: initial Cloudflare Pages project connection.
